# Production hardening roadmap

Bank safety: canonical backend, provider adapter, amount-unit boundary, signed webhooks, CORS, sync states, freshness and reconciliation.

Financial integrity: provenance, duplicate detection, lifecycle, pending visibility, available wealth, FX freshness and goal allocation.

Architecture: IndexedDB-first persistence, modular bank/domain/UI boundaries, provider abstraction and eventual removal of fragile wrapper layers.

Quality: fixtures, migration tests, Playwright, deployment verification, diagnostics and build identity.

Ingestion: smart parser/OCR review, statement preview/conflicts, recurring detection and import dedupe.

Operations: exports, backup verification, documentation and disciplined commits.
